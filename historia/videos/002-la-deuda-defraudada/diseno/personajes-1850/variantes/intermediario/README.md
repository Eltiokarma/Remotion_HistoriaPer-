# Variante del intermediario

Prendas marrones para separar visualmente la función de comprador y la de intermediario. [variante.json](variante.json) extiende el rig del comerciante: conserva sus 900 × 1200 y sustituye cinco piezas, sin ajustar cada una a sus límites. Las otras piezas, los padres y pivotes proceden del rig base.

La variante se creó en VectorCraft mediante MCP. El original conserva las capas y expresiones. La figura no es un retrato documentado de Domingo Elías. Borrador pendiente de Gerson; no tiene animación validada.
