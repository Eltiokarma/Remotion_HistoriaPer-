# Preparación, pausa y paso

Seis bustos y una pose de carga, creados en VectorCraft mediante MCP el 10 de noviembre de 2026. [poses.json](poses.json) indica el rig, el recorte y las rotaciones. El rostro mantiene una nariz interior y la oreja diferenciada.

Los bustos de preparación usan el brazo cercano a −17,5° CSS y el antebrazo a −25°, con la mano relajada; los estados quietos conservan la atención y la boca en reposo. El paso del trabajador conserva el agarre de la carga y articula las piernas.

Las SVG recortadas son referencias del encuadre. Animar con las 135 piezas alineadas de 900 × 1200 y sus pivotes; no mover el busto entero para fingir el gesto. La variante marrón extiende el comerciante. No se modificó el canon.
