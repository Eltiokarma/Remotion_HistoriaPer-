# Criterios de Gerson

**Vacío a propósito.** Aquí van los criterios con los que Gerson aprueba o rechaza una muestra o una
escena, en sus palabras, cuando revise la tanda 1 (tarea `t1-revision` del roadmap). No se completa
con suposiciones del agente.

Formato para cada entrada:

- **Qué miró:** muestra o escena, y el cuadro o tramo si aplica.
- **Veredicto:** aprobado / no aprobado / aprobado con cambios.
- **Por qué, en sus palabras:** cita o paráfrasis marcada como tal.
- **Regla que se deriva:** lo que el agente debe hacer distinto la próxima vez.
- **Dónde aplica:** este canal, esta serie, o solo este tipo de escena.

Cuando haya criterios, se resumen en `SKILL.md` §2 o §5 para que el agente los aplique antes de
mostrar un resultado.
